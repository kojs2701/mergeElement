# 원소 합성 - 화학물질 만들기 🧪

## 📋 프로젝트 개요

원소들을 합쳐 화학 물질을 얻는 웹사이트입니다. 드래그 & 드롭으로 원소를 결합하여 새로운 화학물질을 만들 수 있습니다.
우주 테마의 신비로운 배경과 3D 분자 시각화로 더욱 몰입감 있는 경험을 제공합니다.

###   버전별 접속 방법

- **데스크톱 버전**: [index.html](index.html) - 전체 화면 최적화 (1920x1080 이상)
- **모바일 버전**: [mobile.html](mobile.html) - 모바일 기기 전체 화면 지원 (세로/가로 모드 모두 지원)

### 🌐 반응형 지원

## 🎯 핵심 기능

### 1. 원소 (Element)
- **클래스 구조**: `Element` 클래스로 정의
- **주요 속성**:
  - `name`: 원소의 이름 (예: "수소")
  - `symbol`: 원소의 기호 (예: "H")
  - `color`: 원소의 색상 (그래디언트)
  - `discovered`: 해금 여부
  - `count`: 보유하고 있는 개수

### 2. 화학물질 (Compound)
- **클래스 구조**: `Compound` 클래스로 정의
- **주요 속성**:
  - `name`: 화학물질명 (예: "물")
  - `formula`: 분자식 (예: "H₂O")
  - `components`: 결합된 원소와 개수 (예: `{H: 2, O: 1}`)
  - `info`: 화학물질에 대한 정보
  - `discovered`: 해금 여부

### 3. 게임 상태 (Game)
- **클래스 구조**: `Game` 클래스로 정의
- **주요 기능**:
  - 원소 및 화학물질 관리
  - 드래그 & 드롭 이벤트 처리
  - **정확한 개수 체크** (H 2개, O 1개 필요)
  - 합성 로직 처리
  - **분자 3D 시각화** (130도 각도로 배치)
  - **정보 모달 팝업** 표시
  - UI 렌더링

## 🎮 게임 플레이 방식 (개선된 버전)

### 게임 시작
1. **H 2개**, **O 1개**를 가지고 시작합니다.

### 물(H₂O) 만드는 과정
1. **왼쪽 사이드바**에서 **H 원소** 드래그
2. **중앙의 드롭 존**에 드롭 (첫 번째 원소)
3. 다시 **H 원소** 또는 **O 원소** 드래그
4. 같은 드롭 존에 드롭 (두 번째 원소)
5. 조건을 만족하면:
   - **3D 분자 시각화** 표시 (O 가운데, H 양옆 130도 각도)
   - **플로팅 애니메이션** 실행
   - **정보 모달 팝업** 자동 표시
   - **원소 개수 감소 (H: -2, O: -1)**
   - **분자의 이동** 3D로 분자를 시각화 한것은 수집품 화면에서 벽에 부딪히면서 돌아다녀야함.
### 현재 가능한 합성
- **H * 2(두개가 꼭 들어가야함) + O = H₂O (물)**
  - H는 정확히 2개, O는 정확히 1개 필요
  - 원소 조합 순서는 상관없음 (H+O 또는 O+H 모두 가능)
  - 필요한 개수가 없으면 "원소 부족" 메시지 표시

## 🌌 디자인 특징

### 우주 테마 배경
- 검은색 배경에 별처럼 빛나는 효과
- 신비로운 분위기를 연출하는 사이안(Cyan) 색상의 강조
- 반투명한 glassmorphism 효과로 부드러운 UI

### 3D 분자 시각화
```
        H (왼쪽, 130도)
          \
           O (중앙)
          /
        H (오른쪽, 130도)
```
- 실제 물 분자의 각도를 반영한 배치
- 채 결합을 표현하는 연결선
- 플로팅 애니메이션으로 생동감 있는 표현

### 색상 테마
- **수소 (H)**: 보라색 그래디언트 (`#667eea` → `#764ba2`)
- **산소 (O)**: 핑크 그래디언트 (`#f093fb` → `#f5576c`)
- **강조색**: 사이안 (`#00ffff`)
- **배경**: 깊은 우주 검은색 (`#1a1a2e` → `#000000`)

##피드백
- **원소와 분자의 종류**가 늘어나면 좋겠다.
- **시각적인 게임요소** 게임 요소가 늘어나야 한다(의인화가 들어가면 더 좋음), (호기심 자극).
- **사운드**
- **친절하지 않음** 튜토리얼 추가하면 좋겠음
- **게임의 목적이 없음** 아무리 자유도 높은 게임이라도 퀘스트가 있는 것처럼 목적이 있어야함.
- **게임의 느낌이 없음** 좀 더 게임처럼 보이면 재미가 있을 듯. 
- **저장** firebase 같은 곳에 해도 되고, 코드를 만들어 그 안에서 데이터를 가져올 수 있게 만들어도 됨(에 : H61O52C2N0 --> H 61개, O 52개 C 2개 N 0개(이 경우에는 해금이 되었다는 뜻임), CI(아예 해금이 안됨), 이외에도 분자의 정보까지 넣을 수 있음).
- **레시피를 원소 주기율 표** 형식으로 만드는 것도 괜찮다.
